# Articulation images — Qur'anic pronunciation (Tajweed), Dūrī ʿan Abī ʿAmr

51 files in two folders. Both are named identically so the annotated version of any base image is easy to find.

## Folders

- `A01`–`A15`, `B01`–`B05`, `C01`–`C05` (this folder) — **base illustrations**, no markings. Consistent style: side view faces left, top view has the incisors at the top, lips are straight-on. Use these for animation reference (trace the tongue outline to get keyframes) and anywhere you need a clean image to draw your own marks on.
- `annotated/` — the **same images with teaching marks already drawn**: red dot = where the tongue touches; blue arrow = airflow path; red dashed ring = the part of the tongue that rises; red band = the edge of the tongue that presses; numbered dots = zones. Use these as the static reference images in lessons. Also contains `X01_mouth_map.png`, an overview built from A01 with all 11 articulation zones numbered and an Arabic key.

## Known limitations (be honest with learners)

- These are simplified teaching illustrations, not anatomical drawings.
- A08: the drawing does not show the soft palate lowered; the nasal arrow in the annotated version carries that meaning.
- A15: the generator raised the whole tongue; only the front should rise for imālah.
- Contact areas for ك and ج ش ي are drawn wider than real speech; the red dot marks the true point.
- A02 uses the rest image; the ع ح constriction is deep in the throat and is indicated by the numbered dot only.

## Naming and format

All files are PNG (some were saved from JPEG sources), 1024×1024 for A, ~1024×540 for B and C. Letter names in the filenames are transliterations; the Arabic letters are in the tables above.
